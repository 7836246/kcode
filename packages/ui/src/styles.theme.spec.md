# 浅色页背景

## 行为

浅色主题（Zai Light）的页面背景对齐 ChatGPT / Codex 登录页那种纯白，不是暖米色，也不再用冷灰 `#f8f8f8`。

- 页面：`#ffffff`
- 侧栏 / 窗口外沿：`#fafafa`，贴近内容区的近白，不再用半透明灰压暗
- 卡片、输入同样是白

深色主题不改。

## 所有者

`packages/ui/src/styles.css` 的 `.theme-zai-light` 是浅色语义色的唯一投影。

## 验收

- 新建任务空态和工作区浅色背景是纯白
- 左侧栏比内容区只浅一层，不发暗
- 没有暖黄 / 米色倾向
- 桌面右侧内容卡四角 16px，并与侧栏留出 4px 近白缝
