# 侧栏资料菜单不再提供登录入口

## 行为

KCode 只要求配置供应商 API Key，不再把账号登录当作产品入口。

侧栏和设置页资料菜单：

- 未登录时展示「KCode」，不再展示「连接使用」
- 不再提供「连接使用」菜单项
- 已登录时仍可登出

首次启动的供应商配置欢迎页不受影响。OAuth 与账号协议仍保留在运行时，只是 UI 不再主动引导登录。

## 所有者

- 产品是否展示：`WorkspaceSidebarFooter`
- 是否打开欢迎页：`Root` 不再从资料菜单派发 `manual-login`
- 登录态：仍由 auth store / `user` 拥有

## 验收

- 未登录时资料按钮文案是 KCode，不是「连接使用」
- 资料菜单不再出现「连接使用」
- 设置页资料菜单与工作区侧栏行为一致
