# 帮助菜单不再提供官方产品入口

## 行为

帮助菜单不再展示官方文档、社群、问题上报和产品需求入口。用户只配置供应商，不走官方账号或官方反馈通道。

桌面端保留：

- 资源管理器
- 检查更新（更新器可见时）
- 关于 KCode

Web 端没有资源管理器和关于窗口，帮助按钮不渲染。命令面板也不再提供文档、社群、问题上报和登录命令。

运行时仍保留 feedback / community / docs 的平台能力，错误页等内部入口可继续复用。

## 所有者

- 产品是否展示：`WorkspaceHelpMenuButton` 与 `createQuickPickCommands`
- 桌面原生帮助菜单：`buildApplicationMenuTemplate`
- 反馈提交与外部链接：仍由 Feedback store / `IPlatformService` 拥有

## 验收

- 帮助下拉不再出现「产品文档 / 用户社群 / 问题上报 / 给产品提需求」
- 桌面端仍能打开资源管理器和关于窗口
- Web 端不出现空的帮助按钮
- 命令面板搜索「产品文档 / 用户社群 / 问题上报 / 连接」不再命中对应命令
