# 无可用模型不再引导升级

## 行为

KCode 只通过配置供应商和模型使用，不再提供编程套餐购买或升级页。

无可用模型横幅：

- 文案只提示配置供应商和模型
- 只保留「配置」，不再出现「升级」
- 配置仍打开模型供应商设置

额度横幅、侧栏、设置套餐卡和输入框用量入口也不再打开购买/升级弹窗。

运行时 entitlement / OAuth 协议可保留，产品不再挂载 `CodingPlanUpgradeDialog`。

## 所有者

- 横幅展示：`ChatErrorBanner`
- 是否打开设置：`SessionPane` 的 `onOpenModelSettings`
- 购买弹窗：不再由 `Root` 挂载

## 验收

- 无可用模型横幅没有升级按钮
- 文案不再出现「开通编程套餐」或 Upgrade
- 点击配置仍进入模型供应商设置
- 应用内不再出现升级/购买编程套餐页面
